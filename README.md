I just finished building my Task Manager web app! 🚀

It is a frontend project made with HTML, CSS and JavaScript, and it taught me a lot about how real apps are structured.

What it can do:
✅ Sign up page with form validation
✅ Add, edit, complete and delete tasks
✅ Set priority and due date
✅ Filter tasks: All, Completed, Pending, Important
✅ Live counters for every task status
✅ 3 themes: purple, light and dark
✅ Animated background and a success popup when a task is added
✅ Works on mobile, tablet and desktop

The hardest part was fixing bugs in my JavaScript and making the theme system work on both pages using CSS variables. I am happy with how it turned out.
